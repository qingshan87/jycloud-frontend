# JYCloud 前端开发手册

> 适用于 `jycloud-frontend` 仓库（JYCloud 统一前端控制台）。

## 一、服务划分

| 服务 | clientId | 定位 | 接口前缀 |
| --- | --- | --- | --- |
| jy-user | jy-user | 公共接口服务：认证、菜单、我的应用、个人资料、修改密码，所有业务系统共用 | `/api/jy-user/**` |
| jy-ucenter | jy-ucenter | 用户中心：用户管理、角色管理、部门管理、授权 | `/api/jy-ucenter/**` |
| jy-setting | 1111 | 设置平台：租户、应用、菜单、字典 | `/api/jy-setting/**` |
| 其他业务系统 | 各自 clientId | 按需新增 | `/api/<服务>/**` |

后端接口地址以 `D:\item\jy-code\JYCloud\jycloud\web` 下各服务的 Controller 为准，前端不自行臆造接口。

## 二、目录规则

不同服务必须在 `src/api` 与 `src/pages` 下建立独立目录/文件，禁止跨服务混用。

```text
src/
├── api/
│   ├── auth.ts               # jy-user 公共：认证（登录/退出/切换租户）
│   ├── permission.ts         # jy-user 公共：菜单树、我的应用 apps
│   ├── account.ts            # jy-user 公共：个人资料、修改密码
│   ├── model/userModel.ts    # jy-user 公共模型
│   ├── ucenter/              # jy-ucenter：用户中心业务
│   │   ├── user.ts           # 用户管理
│   │   ├── role.ts           # 角色管理
│   │   ├── dept.ts           # 部门管理
│   │   ├── authority.ts      # 用户授权 / 菜单树
│   │   └── model.ts          # jy-ucenter 模型
│   └── setting/              # jy-setting：设置平台业务
└── pages/
    ├── user-center/          # jy-ucenter 页面
    │   ├── user/index.vue    # 用户管理
    │   ├── role/index.vue    # 角色管理
    │   └── dept/index.vue    # 部门管理
    └── setting/              # jy-setting 页面
```

## 三、页面规则

1. **个人中心（可编辑）、修改密码**：不做动态路由、不进菜单。放在右上角 `[用户名]` 下拉框中，点击后以弹窗展示：
   - 组件：`src/layouts/components/ProfileDialog.vue`、`PasswordDialog.vue`
   - 接口：jy-user 公共接口（`/jy-user/system/user/profile/update`、`/jy-user/system/user/password/update`）
2. **用户名展示字段**：优先 `realname`，没有则用 `username`（登录时已按此规则写入 `userInfo.name`）。
3. **菜单页面功能**：如 用户管理 / 角色管理 / 部门管理 等，均走动态路由，由后端菜单表（`t_menu`）驱动，前端只建页面组件，组件路径与菜单 `component` 字段一致。

## 四、接口规则

1. 公共能力（认证、菜单、我的应用、个人资料、修改密码）统一使用 **jy-user**，所有业务系统共用，不在业务服务中重复实现。
2. 业务接口按服务划分（jy-ucenter / jy-setting / 其他），请求头 `clientId` 自动携带当前应用上下文。
3. **前端缺接口时**：先给出接口需求建议（方法、路径、入参、出参），与后端确认后再开发；**不得擅自开发服务端代码**。
4. 接口响应统一 `{ code, data, msg }`，成功 `code === 200`，前端请求层已统一处理。

## 五、权限标识规范

- 权限编码与后端 `t_menu.perms` 一致，前缀按服务：`jy-ucenter:*`、`jy-setting:*` 等。
- 前端权限标识统一维护在 `src/constants/permission.ts` 的 `PERM` 常量中，页面按钮用 `v-permission="PERM.xxx.yyy"` 控制显隐。
- 新增/变更权限：改后端菜单数据 + 同步 `PERM` 常量 + 页面挂指令。

## 六、菜单 / 路由约定

- 菜单树来自 `GET /jy-user/system/user/router/menu`（按当前用户、租户、clientId 过滤），前端动态生成路由与侧边栏。
- 页面组件路径对应 `src/pages` 目录，如菜单 `component = user-center/user/index` 对应 `src/pages/user-center/user/index.vue`。
- 同租户切换应用不换 token，仅切换请求头 `clientId` 上下文并重建菜单路由。

## 七、接口需求建议（待后端确认）

| 需求 | 建议接口 | 说明 |
| --- | --- | --- |
| 当前用户完整资料 | `GET /jy-user/system/user/profile` | 目前只有 `GET /system/user/{userId}`，需前端保存 userId；建议提供“当前用户”便捷查询 |
| 用户管理 | `GET /jy-ucenter/system/user/page` 等 | 已具备：page/create/update/{userId}/password/reset/username/update |
| 角色管理 | `GET /jy-ucenter/system/role/page` 等 | 已具备：page/create/update/detail/{roleId}/delete/{roleId}，RoleDTO 携带 menuIds |
| 部门管理 | `GET /jy-ucenter/system/dept/tree` 等 | 已具备：tree/{deptId}/create/update/delete |
| 用户授权 | `/jy-ucenter/system/user-authority/set-role`、`list-role` | 已具备；set-menu/list-menu 预留 |
| 菜单树（角色授权用） | `GET /jy-ucenter/system/menu/tree` | 已具备 |
